# Обновление воркера до мультикомпанийной версии (QR-подключение из CRM)

Раньше воркер обслуживал один Telegram-аккаунт, вход делался вручную (номер
телефона + код прямо в консоли сервера). Теперь воркер умеет обслуживать
СРАЗУ много компаний — каждая подключает свой личный Telegram сама, по
QR-коду прямо в интерфейсе CRM (Интеграции → Личный Telegram → «Подключить
по QR-коду»), без доступа к серверу.

## Что нужно сделать на сервере (VPS)

1. **Взять новый секрет.** Значение `CRM_WORKER_TOKEN` — это то же самое
   значение, что уже лежит в секрете проекта `TG_PROXY_TOKEN` (посмотреть
   можно там же, где вы его когда-то создавали).

2. **Обновить файлы воркера** — скопировать на сервер новые версии:
   - `worker.py`
   - `.env.example` → на основе него обновить свой рабочий `.env`

   В `.env` теперь нужно:
   ```
   TG_API_ID=<как и раньше>
   TG_API_HASH=<как и раньше>
   CRM_WEBHOOK_URL=<как и раньше>
   CRM_WORKER_TOKEN=<значение секрета TG_PROXY_TOKEN>
   ```
   Поля `CRM_COMPANY_ID` и `CRM_WEBHOOK_KEY` **больше не нужны** — теперь
   воркер сам узнаёт, какие компании подключены, и ключ каждой из них,
   через CRM.

3. **Старая сессия.** Если у вас уже был подключён Telegram через старую
   версию (`session.session` в корне папки воркера) — эта сессия была
   привязана к одной компании через `.env`. В новой версии сессии хранятся
   в подпапке `sessions/<company_id>.session`. Проще всего: переподключить
   тот же Telegram-аккаунт заново через QR в CRM (займёт 10 секунд) —
   старый файл `session.session` можно после этого удалить.

4. **Перезапустить сервис:**
   ```
   sudo systemctl restart crm-worker
   sudo systemctl status crm-worker
   ```
   Файл `crm-worker.service` не менялся — команда запуска та же.

5. **Проверить логи:**
   ```
   tail -f /opt/crm-worker/worker.log
   ```
   При старте должна появиться строка `[qr-worker] zapushchen, ozhidayu
   zayavki na podklyuchenie ot CRM...`

## Как теперь подключает Telegram каждая компания

1. Сотрудник компании заходит в CRM → Интеграции → «Личный Telegram»
2. Нажимает «Подключить по QR-коду» — появляется QR-код прямо в браузере
3. Открывает Telegram на телефоне → Настройки → Устройства → «Подключить
   устройство» → сканирует код
4. Через пару секунд в CRM появляется «Подключено: Имя Фамилия»

Никакого доступа к серверу или вашей помощи для этого не требуется.

## Ограничения текущей версии

- Аккаунты с включённым облачным паролем (2FA) пока не поддерживаются —
  воркер покажет понятную ошибку и предложит временно отключить пароль в
  Telegram. Можно доработать позже, если понадобится.
- MAX (личный аккаунт) — кнопка в интерфейсе есть, но подключение ещё не
  реализовано (только Telegram).
